# 食物链 · 荒野生存博弈

基于用户提供的《食物链》核心游戏流程与机制 V1.0 实现的中文多人网页策略游戏。浏览器即可游玩，支持 1 人加 7 位电脑的练习模式，以及最多 8 位真人的邀请房间。联机不足 8 人自动补电脑。

**在线游玩：[GitHub Pages](https://aidong27.github.io/food-chain-wilds/)** · [原站](https://food-chain-wilds.food-chain-game.workers.dev/)

本仓库对应原生产版。恢复时，原提交构建出的 HTML、JavaScript、CSS 与原站文件逐字节一致。后来独立部署的 `food-chain-wilds-preview` 重构版不属于本次发布。

GitHub Pages 托管前端与插画；房间、机器人、规则判定、持久化和 WebSocket 继续使用原 Cloudflare Worker。这里是可联机的游戏，需要联网，单人练习也依赖后端。原站与 Pages 可以通过同一个房间码联机；各浏览器标签页的席位凭证独立，不会跨站自动同步。

本次新增 Pages 子路径与邀请链接支持，以及 Worker 的精确来源白名单。没有修改游戏规则、房间存储表、Worker 名称、Durable Object 类名或 migration，也没有合入旧项目的 Git 历史和测试会话记录。

## GitHub Pages 与后端部署

```sh
npm ci
npm test
npm run build:pages
```

`dist-pages/` 是可上传的静态产物。`main` 分支更新后，GitHub Actions 会运行测试、构建并部署到 Pages；Pages 来源需要设为 GitHub Actions。流程仅使用 GitHub 自动提供的发布身份，不需要 Cloudflare 密钥。

`vite.config.ts` 的 Pages 模式配置了 `/food-chain-wilds/` 基路径与原 Worker 的公开地址。Worker 在 `wrangler.jsonc` 中仅额外允许 `https://aidong27.github.io`，处理 JSON 预检请求，并在 WebSocket 升级前执行相同来源校验。迁移到其他账号时须同时调整这两个公开配置；不要设为通配符。

后端独立发布，`npm run deploy` 会更新现有 Cloudflare Worker，应由拥有该服务的维护者通过已有 Cloudflare 登录执行。Pages 工作流不会部署或迁移后端。仍使用原有 `GameRoom` SQLite Durable Object 与 `v1` migration，不能通过删除房间存储来更新站点。

[发布来源与验证记录](docs/DEPLOYMENT.md)说明本次部署范围和检查结果。没有附加开源许可证。

## 已实现

- 固定 7 回合：公共交流、秘密投放、自由行动、局部痕迹、依次私下通话、获取食物、生存结算。
- 8 种唯一且隐藏的动物身份，6 个相邻关系对称的地区，地图插画与动物肖像。
- HP、SP、透支、短周期饥饿、逐轮收紧的地图食物、捕食、食腐、技能与轮换先手。
- 躲藏只消除空间痕迹，不提供捕食免疫；捕食包括隐藏的有效目标。
- 私信每回合 5 条，公开消息 1 条，每条最多 50 个 Unicode 字符。配额不累计。
- 公共语音主动加入、离开；私人通话按席位选择、需对方接受、双方额度共享、30 秒到时结束。
- 推理笔记、七回合结算、全身份揭晓、本玩家可见记录导出。
- 服务端判定、逐玩家视图过滤、不可伪造的席位令牌、同源检查、消息速率与大小限制。
- SQLite Durable Object 持久化，刷新重连，24 小时房间过期清理。主动离开大厅会转移房主，对局内离开由电脑托管。
- 桌面与手机布局，键盘可用的原生表单和模态框，音效开关，减少动态效果支持。

## 补全的规则

原文第 20 节留空内容在本实现中以可调规则落地；原始 DOCX 未被修改。

| 动物 | HP | SP | 饥饿阈值 | 食物 | 技能 |
|---|---:|---:|---:|---|---|
| 灰狼 | 5 | 4 | 1 | 捕食鹿、兔、野猪；伤害 2 | 嗅觉感知当前及相邻地区猎物数量 |
| 赤狐 | 4 | 5 | 2 | 捕食兔、蛇；伤害 1 | 读取一条涉及同地区玩家的历史私信 |
| 山猫 | 4 | 4 | 2 | 捕食兔、渡鸦、赤狐；伤害 1 | 本回合下次命中伤害 +1 |
| 游蛇 | 3 | 4 | 2 | 捕食兔、渡鸦；伤害 1 | 抹除本地痕迹，下次命中伤害 +1 |
| 野兔 | 4 | 5 | 2 | 地图草食 | 跳至相邻地区并抹除两地痕迹 |
| 麋鹿 | 5 | 4 | 2 | 地图草食 | 感知本地区是否存在天敌 |
| 野猪 | 5 | 4 | 2 | 地图草食 | 本回合每次受伤 −1，最低 1 |
| 渡鸦 | 3 | 5 | 3 | 遗骸或地图草食 | 查看一个指定地区的痕迹 |

每回合普通行动额度为 2，每次移动、躲藏、尖叫或技能均花费 1 SP；技能每回合一次。透支先扣 1 HP，再将 SP 恢复为上限的一半（向上取整），最后支付本次费用；透支致死则中止行动。

捕食命中即恢复 3 SP，无需击杀；普通采食恢复 3 SP，渡鸦采食恢复 2 SP、食腐恢复 4 SP。均不恢复 HP。每回合地图资源总量在第 1–2 / 3–5 / 6–7 回合分别为 4 / 3 / 2。遗骸保留到死亡后的第 2 回合结束。

**持续饥饿**：连续未进食达到阈值后，每一回合扣 1 HP，直到进食才清零。这样无法靠躲在无资源区、不采取行动来稳定活过七回合。

食物阶段每人最多一次尝试，按席位轮换先手；失败也花费体力并在本地区暴露。未锁定的选择超时后按默认规则处理：未投放者自动分配，未选择食物者放弃，不代替玩家消耗 SP。

通话选择窗口 15 秒，接通后 30 秒。拒绝不扣机会，但当前发起人的选择阶段结束。每回合每人最多参与一次已接通的通话，作为接听方也消耗机会。语音从不录制或转写，SDP/ICE 只实时转发、不写入数据库。

所有存活者共同获得生存胜利。积分为 `存活 10 + 剩余 HP×2 + 进食次数×2 + 捕食命中×3 + 正确推理×2 − 错误推理`，最低 0；排名先展示存活者，再按分数排列。死亡只公开身份，不公开死亡地点；观战仍保持原玩家的局部视野。

## 技术与运行

前端为 TypeScript + Vite，后端为 Cloudflare Workers + 每房间一个 SQLite Durable Object。客户端没有权威判定，后端不会发送其他存活玩家的身份、真实位置、HP/SP、秘密选择或无权查看的私信。

```sh
npm ci
npx wrangler types
npm run build
npm run preview:worker
```

完整游戏在 `http://localhost:8787`。若需要前端热更新，在另一终端运行 `npm run dev`，Vite 会把 `/api` 和 WebSocket 转发到 8787。

```sh
npm test
node tests/network.mjs
npx wrangler deploy --dry-run
npm run deploy
```

运行网络测试时不要同时重建前端或修改后端；Wrangler 热重载会断开测试用 WebSocket。`GAME_BASE_URL` 可用于同一套线上端到端验证。

`wrangler.jsonc` 使用现有 Cloudflare 登录；源码不包含账号令牌或 API Key。网页 `sessionStorage` 仅保存当前标签页的随机席位令牌，`localStorage` 仅保存昵称与音效偏好。关闭标签页后无法恢复原席位；同标签页刷新可以恢复。

## 原生产版验证与限制

以下数字记录原生产版的历史验收；本次 Pages 迁移的实际验证见上面的发布记录。

- 18 项核心测试包括信息隔离、躲藏仍可被捕食、透支、食物不回血、秘密投放、消息额度、通话时序、饥饿、技能、锁定选择和死亡权限。
- 200 局固定种子模拟验证全部身份均能完成七回合，资源不出现负数、SP 不越界、结算有效。它是规则健全性检查，不代表真人平衡性已完成验证。不同身份难度有意不相同，尤其野兔、游蛇依赖移动与情报。
- 13 项网络检查通过，使用三个真实 WebSocket 客户端验证房主转移、房间同步、私信隔离、语音信令权限、投放保密、行动判定、通话、重连、同源限制、无效令牌和完整七回合结算。
- 浏览器实测了桌面界面与 390×844 手机界面、真实操作与 WebMCP 地图选择的成功/失败路径。
- 正式 Cloudflare 地址实际完成七回合对局，结算页正确揭晓全部八种身份。相同网络集成检查也已在正式地址通过。
- 公共语音使用两个独立浏览器端和合成音源验证，两端 WebRTC 都达到 connected，分别收到超过 1,300 个音频包，音频能量大于 0。验证时未访问真实麦克风。私人通话接受、30 秒超时转入食物阶段、连接自动关闭均已实测。
- WebRTC 使用公开 STUN，当前没有 TURN 中继。严格 NAT、防火墙或企业网络下可能无法建立音频连接，书面消息仍可正常使用。真实多设备跨网络语音仍需要真人试玩确认。
- 电脑玩家使用固定策略与预设回复，不使用外部大模型 API，也不读取其他玩家的隐藏身份来决策。
- 房间 24 小时过期，没有跨设备账号或永久历史战绩。房间代码用来邀请加入，不应当当作保密通信工具。

地图和动物插画由 ImageGen 为本项目生成，已转为本地 WebP 资源。实现参考 Cloudflare 官方的 [WebSocket Hibernation](https://developers.cloudflare.com/durable-objects/examples/websocket-hibernation-server/) 与 [Workers 静态资源](https://developers.cloudflare.com/workers/static-assets/binding/) 文档。
